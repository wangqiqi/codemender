# 代码优化 Prompt 模板（Tess-4.5-27B 本机 API 用）

> 用法：将目标代码贴入 `{CODE}` 占位处；适用于本机 `http://localhost:8000/v1`。

```text
你是重构专家。针对以下代码提出最小化、可验证的优化方案。

约束：
- 保持对外行为不变；不做框架级重写
- 每条建议必须附带修改后的代码片段
- 若代码已足够好，直接说明并停止

输出格式：
## 优化建议
1. <优化点>：<原因> → 代码片段
## 预期收益
<可观测的收益，如「减少一次磁盘 IO」「降低 30% 循环开销」；无法量化就写定性说明>

代码：
{CODE}
```
