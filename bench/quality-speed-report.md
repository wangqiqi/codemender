## TASK-002 · 投机参数矩阵（draft-p-min）✅ 已定论

| draft-p-min | 总时长(300tok) | draft 接受率 |
|-------------|----------------|--------------|
| **0.00（默认）** | **2.17s** ✅ | 85.7% (144/168) |
| 0.30 | 2.32s | 83.9% |
| 0.50 | 2.39s | 86.1% |
| 0.75 | 2.49s | 90.9% |

**结论**：提高 p-min 接受率虚高（跳过更多 draft）但总时长单调变差 → **默认 0.00 已最优**，不引入配置项。

## TASK-003 · imatrix 量化质量实验 — ❌ 用户否决（2026-11-14）

原计划：下载 Q8_0（28.6GB）作量化源 → imatrix → 增强版 Q4_K_M。

**用户算账否决**（采纳）：
- Q8_0 权重 29G 全 GPU 需 ~35G ❌ 超 24G 约 11G → 卸 ~1/3 层权重到 CPU → ~200ms/token → **3-5 tok/s**（权重卸载每 token 都付费，比 KV 卸载贵一个量级）
- 27B 模型 Q8 vs Q4_K_M 的 perplexity 差距通常 <1% — 质量收益微小
- 卸层后 draft-mtp 也失去意义（投机 + 慢权重 = 更慢）
- 本仓 KV-offload 实测已证明「离开全 GPU 就没有甜点」— 权重卸载是更严酷版本

**行动**：Q8_0 下载中止、半成品清理（磁盘 1.1T 可用确认）。真要 Q8 级质量 → 等更大显存/双卡。
